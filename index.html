Sage reads live Chainlink prices for eight tokenized stocks on Base, writes a sourced brief for each one, and anchors the brief’s hash onchain so anyone can check it existed. The hash is public. The brief itself — positions, notes, the rewrite — is sealed inside a Terminal 3 enclave, and only the hash ever leaves it.

Read first — not financial advice. Research only — no real trading, no custody, no token launch. Tokenized stocks are not shares and carry no voting rights. Not available to US users for trading; this app does not trade.

01 — Live prices

Eight stocks, priced onchain.

Chainlink aggregators on Base mainnet, read through the public RPC — no key. Total Return Values (price × multiplier), 8 decimals, 24/5 market hours. Click a tile to brief that stock.

02 — The brief

A brief you can check.

Fixed, auditable rules — 24h and 7d change, annualised volatility, a momentum score from 0 to 100. If a feed is stale (over 25 hours old) the score is withheld, not guessed. Every number names its source.

Onchain anchoring: contract ready, awaiting testnet deployment. The button stays disabled until then — we don't fake a transaction.

03 — Paper portfolio

$10,000 of pretend money.

Simulated trades at the live feed price. Positions are stored only in your browser (localStorage). Nothing here buys or sells anything real.

04 — Rewrite

Rewrite it — your key, your browser.

Paste a Gemini API key to have the brief rewritten in natural language. The key is stored only in your browser's localStorage and is never sent anywhere except Google's API. Without a key, the deterministic brief above is the full product — the agent works with zero keys.

05 — Private briefs · Terminal 3 TEE

The brief stays sealed.

The same brief, sealed: the full brief JSON lives only in a tenant-private TEE key-value map, under its SHA-256 content address. A rewrite runs inside the enclave with an enclave-held Gemini key — the key and the full brief never touch this browser or the CLI. The public anchor above stores only a hash; this layer keeps the text itself private.

Honest limits: this static page cannot open a T3 enclave session (the SDK's WASM worker needs COOP/COEP headers a static host can't send), so sealing and rewriting run from the repo CLI — node t3/cli.mjs seal-brief then node t3/cli.mjs private-rewrite (needs a T3N API key from the Terminal 3 claim page). This panel never sends your brief or any key anywhere; its only network call is fetching the proof JSON above. Contract: contract/ · repo · T3 docs.

06 — How it works

End to end, nothing hidden.

  1. Prices come from Chainlink aggregator contracts on Base (see js/feeds.js for the feed addresses).
  2. The brief is computed by fixed, auditable rules in js/analysis.js — 24h/7d change, volatility, momentum score 0–100. If a feed is stale (>25h), the score is withheld.
  3. Each brief can be anchored onchain as a hash (ResearchAnchor.sol) — testnet deployment pending.
  4. Private Briefs (Terminal 3): the same brief can be sealed into a tenant-private TEE map and rewritten inside the enclave — see the panel above and the repo's T3 CLI.
